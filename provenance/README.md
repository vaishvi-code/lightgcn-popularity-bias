# ARC provenance

These original exports identify the environment and upstream code used for the completed baseline.

- `upstream-commit.txt` records the author-linked LightGCN-PyTorch commit.
- `environment-freeze.txt` records the installed ARC packages. Its local Conda package reference makes it unsuitable as a portable pip requirements file.

Use [the root setup instructions](../README.md#getting-started) and `requirements.txt` to install the direct dependencies. Per-run configuration and history are indexed in [the results guide](../results/README.md).
