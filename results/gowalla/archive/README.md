# Historical measurements

These artifacts preserve intermediate checks before the completed 200-epoch run.

- `lightgcn-k3-training-snapshot.json` records the epoch-16 snapshot.
- `lightgcn-k3-history-excerpt.csv` contains partial training history.
- `lightgcn-k3-seed2020-20261102-164221/` contains the two-epoch check.
- `mf-k0-seed2020-job327066/` contains the completed two-epoch matrix factorization training and validation-evaluation check. Its configuration, metrics, item exposure counts, history, and completion summary verify the zero-layer pipeline.
